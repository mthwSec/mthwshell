# Changelog

## 0.1.0 — 2026-10-23

First public portable release for Windows x64.

- Tabs and split panes with keyboard navigation.
- Git Bash, PowerShell and Command Prompt profiles.
- Eight themes, bundled fonts and appearance preferences.
- Attention indicators and desktop alerts for supported profiles.
- One fresh Home tab for the current Windows user on every launch.
- Portable appearance preferences with a writable-folder fallback.
- Mint M monogram application icon.
